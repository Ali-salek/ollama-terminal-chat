# 💬 چت ترمینالی با Ollama

**فارسی** | [English](README.md)

یک دستیار ساده برای ترمینال که از طریق [Ollama](https://ollama.com) با یک **مدل زبانی محلی** صحبت می‌کند. پاسخ‌ها به‌صورت زنده (استریم) نمایش داده می‌شوند، همه‌چیز روی سیستم خودتان اجرا می‌شود و به کلید API نیازی نیست.

## ✨ امکانات

- 🔒 کاملاً محلی و خصوصی: بدون ابر و بدون کلید API
- ⚡ نمایش زنده‌ی پاسخ (Streaming)
- 🪶 سبک: یک فایل پایتون با فقط یک وابستگی (`requests`)
- 🧯 پیام خطای واضح (خاموش بودن سرور، تایم‌اوت، خطای HTTP)
- 🔁 حلقه‌ی تعاملی: تا وقتی `exit` نزنید می‌توانید سؤال بپرسید

## 📋 پیش‌نیازها

- پایتون ۳.۹ یا بالاتر
- نصب و اجرای [Ollama](https://ollama.com/download)
- دانلود یک مدل (پیش‌فرض: `gemma3:1b`)

## 📦 نصب

</div>

```bash
git clone https://github.com/Ali-salke/ollama-terminal-chat.git
cd ollama-terminal-chat

python -m venv .venv
source .venv/bin/activate        # ویندوز: .venv\Scripts\activate

pip install -r requirements.txt
```

<div dir="rtl">

مدل را دانلود کنید و مطمئن شوید Ollama در حال اجراست:

</div>

```bash
ollama pull gemma3:1b
ollama serve        # اگر Ollama از قبل در پس‌زمینه اجراست، لازم نیست
```

## 🔧 پیکربندی

ثابت‌های ابتدای فایل `terminal_chat_ollama.py` را ویرایش کنید:

| ثابت     | مقدار پیش‌فرض            | توضیح                                   |
| -------- | ------------------------ | --------------------------------------- |
| `MODEL`  | `gemma3:1b`              | هر مدلی که در Ollama دانلود کرده‌اید     |
| `SERVER` | `http://localhost:11434` | آدرس سرور Ollama                        |

با دستور `ollama list` مدل‌های نصب‌شده را ببینید. تایم‌اوت درخواست در تابع `get_response` تنظیم شده است (`timeout=(5, 120)`: ۵ ثانیه برای اتصال و ۱۲۰ ثانیه برای انتظار دریافت داده).

## ⚠️ محدودیت‌ها

- هر پیام **مستقل** ارسال می‌شود و دستیار پیام‌های قبلی را به یاد نمی‌آورد. برای افزودن حافظه، از اندپوینت `/api/chat` در Ollama استفاده کنید و تاریخچه‌ی پیام‌ها را نگه دارید.
- مدل‌های کوچک مثل `gemma3:1b` سریع‌اند اما دقتشان از مدل‌های بزرگ‌تر کمتر است.

## 🗺️ ایده‌هایی برای مشارکت

- افزودن حافظه‌ی گفتگو با `/api/chat`
- دریافت نام مدل و آدرس سرور از آرگومان خط فرمان یا متغیر محیطی
- پشتیبانی از System Prompt
- ذخیره‌ی تاریخچه‌ی گفتگو در فایل
- خروجی رنگی یا رندر Markdown
